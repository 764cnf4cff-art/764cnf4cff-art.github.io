# Rain Flow As 3.0

日语、中文、英语共享借伞网页原型。包含二维码借还登记和伞点二维码生成。

## GitHub Pages 发布

这些文件已经按仓库根目录发布方式整理，无需安装依赖或构建。

目标仓库：你的 GitHub 用户名.github.io
Pages 设置：Deploy from a branch → main → /(root)。

index.html、样式、JavaScript、assets/ 和 vendor/ 需要保持当前相对路径。
部署完成后，使用新的 GitHub Pages 网址打开二维码页面，重新生成二维码。

登记及库存目前仅保存在当前浏览器，不会连接 Google Forms、真实伞架或收费服务。

第三方许可见 vendor/ 目录。
